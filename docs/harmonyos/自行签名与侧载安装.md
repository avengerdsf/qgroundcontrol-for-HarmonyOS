# 自行签名与侧载安装

适用于 QGroundControl **5.1.5 for harmonyOS** 的 **2in1 / Pad / Phone** ARM64 未签名 Release 包，包名为 `org.mavlink.qgroundcontrol`。文件命名为 `QGroundControl-5.1.5-harmonyOS-2in1-Pad-Phone-arm64-<versionCode>-unsigned.hap`。具体版本号、大小、SHA-256 及构建信息以随包提供的 `SHA256SUMS` 和产物核验记录为准。

最低声明 API 23。运行验证范围见[项目说明](../../README.md)；仿真器 unsigned 安装与实体设备签名验签分别记录。

## 准备材料

安装华为官方 DevEco Studio，准备自己的配套 `.p12`密钥库、密钥别名与密码、`.cer`应用证书、已签名 `.p7b` Profile。Profile 包名须为 `org.mavlink.qgroundcontrol`；证书、权限及有效期须匹配。调试 Profile 须包含目标 Pad 的 UDID。Release 构建模式与签名 Profile 类型分别核对，外部分发使用对应的华为发布或指定设备发布流程。

私钥、密码、证书和 Profile 由签名者保管，不随公共 HAP 分享。无需向包提供方发送签名材料。

## 校验、签名与验签

对照本目录 `SHA256SUMS`核对 HAP。修改 DevEco 路径及自己的密钥别名，把 HAP 放入工作目录，把自己的三个签名文件放入 `private`。签名输出、Java 临时目录和工作目录均位于项目 `tmp`；SDK 目录只读。

```powershell
$ErrorActionPreference = 'Stop'
$deveco = 'D:/Progrem/Huawei/DevEco Studio'
$work = Join-Path (Get-Location).Path 'tmp/self-sign'
New-Item -ItemType Directory -Force -Path $work,"$work/private","$work/temp","$work/home" | Out-Null
$env:TEMP = "$work/temp"
$env:TMP = "$work/temp"
$java = "$deveco/jbr/bin/java.exe"
$tool = "$deveco/sdk/default/openharmony/toolchains/lib/hap-sign-tool.jar"
$javaOptions = @('-Xmx768m', "-Djava.io.tmpdir=$work/temp", "-Duser.home=$work/home", '-jar', $tool)
$unsignedName = 'QGroundControl-5.1.5-harmonyOS-2in1-Pad-Phone-arm64-5011501-unsigned.hap'
$unsigned = Join-Path $work $unsignedName
$signed = Join-Path $work ($unsignedName -replace '-unsigned\.hap$', '-signed.hap')
$keyAlias = '填写自己的密钥别名'
$checksumPattern = '^([a-fA-F0-9]{64})\s+\*?' + [regex]::Escape($unsignedName) + '$'
$checksumLines = @(Get-Content -LiteralPath "$work/SHA256SUMS" | Where-Object { $_ -match $checksumPattern })
if ($checksumLines.Count -ne 1) { throw 'SHA256SUMS 中须包含所选 HAP 的唯一校验记录' }
$null = $checksumLines[0] -match $checksumPattern
$expectedUnsignedSha256 = $Matches[1]
if ((Get-FileHash -Algorithm SHA256 -LiteralPath $unsigned).Hash -ine $expectedUnsignedSha256) {
    throw '未签名 HAP 校验值不匹配'
}
if (Test-Path -LiteralPath $signed) { throw '签名输出已存在，请先另行归档' }
if ($keyAlias -eq '填写自己的密钥别名') { throw '请填写自己的密钥别名' }
& $java @javaOptions sign-app `
    -mode localSign -keyAlias $keyAlias -signAlg SHA256withECDSA `
    -appCertFile "$work/private/app.cer" `
    -profileFile "$work/private/app.p7b" -profileSigned 1 `
    -keystoreFile "$work/private/app.p12" -pwdInputMode 1 `
    -inFile $unsigned -outFile $signed -inForm zip `
    -compatibleVersion 23 -signCode 1 -permSign 1
if ($LASTEXITCODE -ne 0) { throw 'HAP 签名失败' }
& $java @javaOptions verify-app -inFile $signed `
    -outCertChain "$work/private/verified-chain.cer" `
    -outProfile "$work/private/verified-profile.p7b"
if ($LASTEXITCODE -ne 0) { throw 'HAP 验签失败' }
Get-FileHash -Algorithm SHA256 -LiteralPath $signed
```

`-pwdInputMode 1`在交互终端输入密钥库及密钥密码。验签导出的证书和 Profile 留在本地 `private`；签名后的 HAP 使用新的 SHA-256，不再具有 unsigned 文件的校验值。

## 安装到 Pad

在 Pad 开启开发者模式与 USB 调试并授权电脑连接。确认目标 Pad 的 HDC 标识及 Profile 授权范围后，只向这个目标安装签名 HAP：

```powershell
$padTarget = '填写已确认的Pad连接标识'
if ($padTarget -eq '填写已确认的Pad连接标识') { throw '请先填写目标 Pad' }
& "$deveco/sdk/default/openharmony/toolchains/hdc.exe" -t $padTarget install -r $signed
if ($LASTEXITCODE -ne 0) { throw '安装失败，请保留错误信息' }
```

同包名更新要求签名身份兼容。签名不一致时保留已有应用与数据，先核查证书和备份需求，不自动卸载。签名校验失败时检查证书配套、Profile 包名、有效期和目标 UDID，勿修改包内内容绕过验证。
